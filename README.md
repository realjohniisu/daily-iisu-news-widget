# Daily iiSU News Web Widget!!
A lighter version of the original [Daily iiSU News Website](https://realjohniisu.github.io/daily-iisu-news/), designed for a square web widget inside of iiSU.
To install, go into iiSU's home page, click on a blank square, add widget, web widget. Move it to your desired place. Then, click the select button while hovering over the widget
